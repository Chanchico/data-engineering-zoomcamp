## 5. Second run: is it still idempotent?

It still idempotent. Dans la première itération de la boucle d'injection,  permet d'écraser supprimer la table. (grace à```to_sql(if_exists="replace"```). Et puis dans les itération suivante on passe en mode ```append``` dans ```to_sql(if_exists="append"```, ce qui permet d'ajouter les données après avoir recréé la table. 

Prédiction ex-001 : après 2 runs, 1 369 765 lignes, idempotent. Observé après le 2ᵉ run : COUNT(*) = 1 369 765. La prédiction était correcte.
